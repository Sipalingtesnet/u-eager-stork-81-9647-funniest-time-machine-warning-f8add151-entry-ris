## The entry

One time-machine warning label, at most 120 characters, written to `/output/entry.txt` by a
deterministic Python 3.13 program:

> CAUTION: Ancestors stranded in the past will be reissued to another family, as is.

It is phrased as a straight-faced reissue notice — the calm wording of a lost-property or
salvage-disposal office — for the oldest hazard in the book: an ancestor who does not come home
with you. The turn is saved for the last words, where a stranded relative is disposed of like
surplus stock. Nothing is fetched, generated or randomised; the text is a literal in `main.py`,
so every run writes the same bytes.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program creates `/output` if it is missing and writes the label as UTF-8 with no trailing
newline. It uses only the standard library and exits quietly.
